RPG de Sobrevivência
Um mini RPG de terminal desenvolvido em C# usando o Visual Studio Community 2022. 
O objetivo é sobreviver pelo maior número de rounds possível, explorando uma caverna, encontrando moedas e decidindo quando comprar poções ou descansar.

🎮 Como funciona
A cada round, escolha uma ação:
- Explorar a caverna: encontre um monstro, um tesouro ou uma poção.
- Visitar a loja: compre poções usando as moedas que conseguiu. A poção misteriosa pode ter efeitos positivos ou negativos.
- Descansar: tente recuperar vida, sabendo que também pode sofrer dano.
O jogo termina quando a vida chega a zero. Ao final, são mostrados o total de rounds e as moedas acumuladas.

🧩 Recursos
- Sistema de vida com limite máximo de 100 pontos
- Moedas para comprar itens
- Eventos aleatórios durante a exploração
- Poções com diferentes custos e efeitos
- Sistema de dano, cura e descanso
- Contagem de rounds e condição de fim de jogo
  
🛠️ Tecnologias
- C#
- .NET
- Visual Studio Community 2022
  
▶️ Como executar
1. Instale o Visual Studio Community 2022, caso ainda não tenha.
2. Durante a instalação, selecione a carga de trabalho Desenvolvimento para desktop com .NET.
3. Baixe ou clone este repositório.
4. Abra o arquivo da solução (.sln) ou do projeto (.csproj) no Visual Studio.
5. Execute usando Ctrl + F5 ou clique em Iniciar sem depuração.
Se o projeto já estiver aberto no Visual Studio, basta iniciar a execução pelo botão verde ou usar Ctrl + F5.

📚 Objetivo do projeto
Projeto pessoal criado para praticar lógica de programação e conceitos de C#, 
incluindo classes, propriedades, métodos, condicionais, laços de repetição e geração de eventos aleatórios com Random.
